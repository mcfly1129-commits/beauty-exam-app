・ブラウザの閲覧履歴、キャッシュ、ストレージデータの削除[cite: 3]
・利用端末または利用ブラウザの変更[cite: 3]
・プライベートブラウズ（シークレットモード）での利用[cite: 3]
・端末のストレージ容量不足による自動消去[cite: 3]
・iOS/Safari等の仕様（ITP機能等）による一定期間未アクセスでの自動削除[cite: 3]

プライバシーポリシー

1. 収集する個人情報
本サービスでは、Google認証を通じて以下の情報を取得します[cite: 1, 2]。
・Googleアカウントの電子メールアドレス[cite: 1, 2]
・Google発行の認証用IDトークン[cite: 1, 2]
・アプリ内での学習スコアおよび進捗データ[cite: 2]

2. 情報の利用目的
取得した個人情報は、以下の目的でのみ利用します[cite: 1, 2]。
・学校名簿等のホワイトリストと照合した認証・アクセス制御のため[cite: 1]
・成果報告時のデータ送信、全国ランキング・統計データの算出のため[cite: 2]
・不正アクセスの防止およびシステムセキュリティ維持のため

3. データの管理と第三者提供
当社は、法令に基づく場合を除き、取得した個人情報をユーザーの同意なく第三者に提供・開示することはありません。

4. サードパーティ製ライブラリの利用
本サービスでは、グラフ描画や演出のためにサードパーティ製ライブラリ（Chart.js、canvas-confetti等）を使用していますが、これらに個人情報が渡されることはありません[cite: 1, 2, 3]。
